VERALTET – NICHT IN FIREBASE VERÖFFENTLICHEN
=============================================
Dieses Dokument enthält bewusst KEINE direkte Profil-Firestore-Freigabe mehr.

Ab Spielerportal 3.0 verwaltet ausschließlich Render die Profildaten:
  Firebase Authentication (E-Mail/Passwort) -> Firebase-ID-Token
  -> Render /api/profile/me und /api/profile/complete
  -> Firebase Admin SDK -> Firestore player_profiles_v1

Das Client-Profilmodul profile-core.js darf NICHT direkt auf Firestore zugreifen.
Ein lokales Profil wird nicht angelegt.

Stand 12.10.2026: In der Firebase Console vorhandene Standardregel
  match /{document=**} {
    allow read, write: if false;
  }
für direkte CLIENT-Zugriffe geschlossen lassen.

HINWEIS:
Das Firebase Admin SDK am Render-Server wird durch diese Client-Regel
nicht eingeschränkt. Die Serverzugriffe erfolgen über Dienstkonto und
werden durch die Render-API mit geprüfter Firebase-Identität gesichert.
Keinesfalls „allow read, write: if true“ einsetzen.

Achtung: Dieses Dokument ist ein Hinweistext, keine komplette
Firestore-Regeldatei. Änderungen an produktiven Firestore-Regeln immer
gegen sämtliche verwendeten Sammlungen prüfen.
