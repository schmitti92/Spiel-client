# DOG-Profilbilder

Hier werden neue Profilbild-Motive fuer DOG gespeichert, getrennt von Spielhintergruenden und Wappen.

## Weihnachtsprofilbilder 2026

Bitte das gemeinsame Raster `DOG_Weihnachtsprofilbilder_20_Spritesheet.webp` in diesem Ordner hochladen. Alternativ koennen die einzelnen Profilbilder hier abgelegt werden. Die neuen Profilbilder erscheinen erst im Spiel, wenn der Avatar-Katalog und die Auswahloberflaeche sie einbinden. Freischaltbedingungen muessen separat konfiguriert werden.

Hinweis: Bisherige Profilbilder `profile-avatars.webp` und `profile-avatars-extra.webp` im Repository-Hauptverzeichnis bleiben unveraendert.
