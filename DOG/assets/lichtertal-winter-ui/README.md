# Lichtertal – winterliche Weihnachtsbaum-Stufen

Dieser Ordner enthält die einzeln hochzuladenden PNG-Grafiken für das winterliche Design der zehn Baumstufen.

Die Grafiken werden bewusst ohne Text, Stufennummern und eingebaute Belohnungen erstellt, damit die vorhandene Logik die Werte und Status weiterhin dynamisch darstellt.
