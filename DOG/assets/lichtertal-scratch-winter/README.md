# Lichtertal – Wintermotive für die vier Rubbellose

Die neue Rubbellose-Seite ist bereits in `DOG/christmas-scratch-winter-shop.css` gestaltet.
Die vier zusätzlichen Hauptmotive gehören in **diesen Ordner**:

| Datei | Los | Verwendung |
| --- | --- | --- |
| `01_icon_geschenk.png` | Geschenkelinie | Großes freigestelltes Geschenkbild |
| `02_icon_schneeflocke.png` | Schneeflocken-Bingo | Großes freigestelltes Eisbild |
| `03_icon_wichtel.png` | Magischer Wichtelpfad | Großes freigestelltes Wichtelbild |
| `04_icon_premiumkrone.png` | Premium-Weihnachtslos | Großes freigestelltes Kronenbild |

Die CSS-Regeln benutzen diese Dateinamen bereits. Bis die vier PNGs hochgeladen sind, bleiben die bisherigen Emoji-Symbole als Fallback erhalten. Zusätzliche Grafiken aus dem ZIP sind optional und können bei weiteren visuellen Verbesserungen eingebaut werden.

## Hochladen

Die einzelnen Dateien (nicht die ZIP) hier hochladen:

## Wichtige technische Grenzen

Belohnungschancen, Gewinnsymbole, Preise, Gratisöffnungen, Einstellungen und persönliches Guthaben werden weiterhin serverseitig / aus dem bestehenden JavaScript gesteuert; die Bilder enthalten keine Datenwerte.
