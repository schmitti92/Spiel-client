# Grinch-Event – austauschbare Bilder

Hier liegen die optionalen Grafiken des DOG-Eventreiters **Der Fluch des Weihnachtsmuffels**.

Dateinamen, die die Eventseite automatisch verwendet:

| Datei | Bereich |
| --- | --- |
| `event-banner.jpg` | Titelbild der Eventseite |
| `event-hintergrund.jpg` | Ruhiger winterlicher Hintergrund |
| `grinch-emblem.png` | Emblem im Titelbereich |
| `mission-1.png` | Die gestohlenen Lichter |
| `mission-2.png` | Verfluchte Karten |
| `mission-3.png` | Eiszeit-Chaos |
| `mission-4.png` | Portale und Fallen |
| `mission-5.png` | Finale in der Grinchhöhle |
| `belohnung-finale.png` | Optionales zusätzliches Finalbild |
| `mission-gesperrt.png` | Optionales geschlossenes Missionssymbol |

**Upload:** https://github.com/schmitti92/Spiel-client/upload/main/DOG/weihnachtsevent-bilder/grinch-event

Die Dateinamen müssen unverändert bleiben; PNGs und JPGs direkt hier hochladen, nicht als ZIP. Ohne Upload erscheinen die CSS-Designs und Emoji-Ersatzgrafiken. Die Missionen bleiben eine Designvorschau, bis serverseitiges Grinch-Gameplay implementiert ist.
