# Lichtertal – Geschichtsbuch-Grafikpaket

Hier werden die einzelnen transparenten PNG-Grafiken aus dem Lichtertal-Geschichtsbuch-Grafikpaket abgelegt.

## Upload
1. ZIP-Datei lokal entpacken.
2. In GitHub **Add file → Upload files** auswählen und die einzelnen PNG-Dateien in diesen Ordner hochladen.
3. **Commit changes** bestätigen.

## Verwendungszweck
Buchseiten, goldene Rahmen, Weihnachtsdekoration, Kapitel-Schilder, Navigation und passende Interface-Grafiken. Bestehende Bildnamen beim Hochladen beibehalten.

Die hochgeladenen Bilder sind nicht automatisch auf der Website eingebaut, sondern werden anschließend gezielt im Geschichtsbuch verknüpft.
