# Lichtertal – UI-Dekoration

Hier werden transparente PNG-Grafiken für den DOG-Weihnachtsevent-Bereich **Lichtertal** abgelegt.

## Hochladen

GitHub: **Add file → Upload files**. Die PNG-Bilder einzeln aus dem entpackten ZIP-Archiv hochladen und anschließend **Commit changes** auswählen.

## Verwendung

Dateien aus diesem Ordner sind unter `./weihnachtsevent-bilder/ui-deko/<dateiname>.png` relativ zur Datei `DOG/christmas-event.html` erreichbar. Die UI bindet die Bilder erst ein, wenn die Dateinamen und Platzierungen eingerichtet wurden.
